# Звуки (SFX)

Положи сюда файлы `.mp3` или `.wav`. Имена (любое из списка на событие):

| Событие | Файлы |
|---------|--------|
| spawn | spawn.mp3, spawn.wav, place.mp3 |
| attack_melee | attack_melee.mp3, slash.mp3 |
| attack_ranged | attack_ranged.mp3, arrow.mp3 |
| hit | hit.mp3, hit.wav |
| death | death.mp3 |
| elixir_full | elixir.mp3, elixir_full.wav |
| tower_down | tower_down.mp3 |
| win / lose | win.mp3, lose.mp3 |
| tap / deny | tap.mp3, deny.mp3 |

Источник: https://github.com/Henrylq/Clash-Royale-SFX  
Без файлов игра использует синтез-fallback (Web Audio).

Mute: клавиша **M**.
